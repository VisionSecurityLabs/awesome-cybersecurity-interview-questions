# Contributing

Thank you for helping improve this question bank.

## Question Standards

All questions must test **methodology and thinking**, not memorization. Before submitting, verify:

- [ ] Cannot be answered by 30 seconds of Googling
- [ ] Tests HOW to think, not WHAT to memorize
- [ ] Multiple valid approaches could score well
- [ ] Would be useful in a real interview

## Question Format

```markdown
### Q. [Your question here]

*Difficulty: ⭐⭐⭐ | Format: scenario*

  **What a strong answer covers:**
  - Methodology point 1
  - Methodology point 2
  - Methodology point 3
```

## What Not to Submit

- Definition questions: "What is X?"
- Memorization questions: "List the phases of X"
- Trivia: "What port does X use?"
- Questions with a single correct answer

## Submitting

1. Fork the repository
2. Add your question(s) to the appropriate domain file in `questions/`
3. Open a pull request with a brief description
